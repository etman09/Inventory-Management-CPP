# Inventory Management System 📦📋

## 📝 Description
A robust console-based Inventory Management application developed in C++. This project is designed to handle stock management operations, allowing users to efficiently track, update, and manage product inventory. It demonstrates advanced concepts like Object-Oriented Programming (OOP), dynamic memory management, or data structures for storing item records.

## ✨ Features
- Add New Items: Register new products to the inventory with their details (ID, name, price, quantity).
- Update Stock: Modify the quantity or details of existing items.
- View Inventory: Display a formatted list of all available items in the stock.
- Search Items: Find specific products using their ID or name.
- Delete Items: Remove products from the inventory system.

## 🛠️ Technologies Used
- Language: C++
- Environment: Console / Terminal
